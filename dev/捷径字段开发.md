# 九因 AI 对话 - 字段捷径插件

基于 FaaS 开发和对话 API 的字段捷径插件，固定使用 `gemini-3.5-flash` 模型，支持系统提示词、用户对话提示词和多个图片附件字段输入，一次对话调用，返回 AI 回复文本。

## 使用说明

### 表单字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 九因API key | 文本输入 | 是 | 九因 API 密钥，前往 [九因官网](https://ai.theninefactor.com/) 获取 |
| 系统提示词 | 文本输入 | 否 | 设定 AI 角色与行为规则（system message） |
| 对话提示词 | 文本输入 | 是 | 每次对话的用户消息（user message） |
| 参考图片 | 附件字段（多选） | 否 | 可选的多个图片附件字段，可多选，自动上传到 OSS 后以 vision 格式发送 |

### 工作流程

1. 用户在多维表格中配置捷径表单：填入 OpenAPI Token、系统提示词、对话提示词，可选多个图片附件字段（可多选）
2. 如有图片附件，插件自动下载并上传到 OSS 获取 URL
3. 插件调用 `POST /unified/openApi/v1/chat/completions` 发起对话请求（有图片时使用 OpenAI vision 格式）
4. 模型固定为 `gemini-3.5-flash`，非流式返回
5. AI 回复内容写入当前行的文本字段

### 请求示例（无图片）

```json
{
  "model": "gemini-3.5-flash",
  "messages": [
    { "role": "system", "content": "<系统提示词>" },
    { "role": "user", "content": "<对话提示词>" }
  ],
  "stream": false
}
```

### 请求示例（有图片）

```json
{
  "model": "gemini-3.5-flash",
  "messages": [
    { "role": "system", "content": "<系统提示词>" },
    {
      "role": "user",
      "content": [
        { "type": "text", "text": "<对话提示词>" },
        { "type": "image_url", "image_url": { "url": "<OSS图片URL1>" } },
        { "type": "image_url", "image_url": { "url": "<OSS图片URL2>" } }
      ]
    }
  ],
  "stream": false
}
```

### 返回结果

- 返回类型为**多行文本字段**（FieldType.Text）
- 成功时返回 AI 回复的文本内容
- 失败时返回错误信息

## 本地开发

### 环境要求

- Node.js >= 14.16.0

### 安装与启动

```bash
# 安装依赖
npm install

# 启动本地服务
npm run start
```

### 调试

1. 基于 [FaaS字段捷径调试模板](https://feishu.feishu.cn/base/DiQXbSLkSaGmwUsHkfJcAscunlh?table=tblwp5TejhYSjeNU&view=vewPbLApNL) 复制副本
2. 在侧边栏插件市场中搜索"字段捷径调试助手"，运行并 pin 到侧边栏
3. 点击"打开面板"，配置表单后保存创建捷径字段
4. 点击"调试字段"模拟 FaaS 请求

## 打包发布

### 打包

```bash
# 在项目目录下执行
npm run pack
```

执行后会在 `output/` 目录生成 `output.zip` 文件。

### 发布

1. 将 `output/output.zip` 上传到飞书字段捷径插件平台
2. 上线需将项目提交到 Github，然后填写 [多维表格捷径插件表单](https://feishu.feishu.cn/share/base/form/shrcnwTXnFVAbMPOSeaOFwIAnbf)

### 其他命令

| 命令 | 说明 |
|------|------|
| `npm run start` | 启动本地调试服务 |
| `npm run build` | 构建项目 |
| `npm run pack` | 打包为 zip（用于发布） |
| `npm run dev` | 开发模式 |
